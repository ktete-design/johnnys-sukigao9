# HISTORY OF JOHNNYS SUKIGAO 9

スマホ向け「歴代Johnnys好き顔9」のプロトタイプです。

## 今できること
- 名前・グループ名で検索
- グループで絞り込み
- 候補者を9人まで選択
- 9人をドラッグして順位を変更
- 結果カードをPNG保存

## 使い方
1. `script.js` の `candidates` に候補者を追加
2. 写真を使う場合は `images` フォルダを作る
3. 各候補者に `image:"images/xxx.jpg"` を追加
4. GitHubのリポジトリに `index.html`, `style.css`, `script.js`, `images/` をアップロード
5. GitHubの Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択
6. 公開URLを開く

GitHub Pagesはリポジトリ内のHTML/CSS/JavaScriptをそのまま公開できる静的ホスティングです。

## 注意
人物写真には著作権・肖像権などが関係するため、公開サイトで使う画像の権利関係は自分で確認してください。
